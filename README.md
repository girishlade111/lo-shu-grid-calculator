# Lo Shu Grid Calculator

A free online Lo Shu Grid calculator — the traditional Chinese numerology system based on your birth date. Enter a date of birth and instantly get your complete 3×3 Lo Shu magic-square chart with number placements and interpretations.

## Features

- **Instant Lo Shu grid** from any birth date
- **Number placement chart** — see which numbers appear, repeat, or are missing
- **Traditional interpretations** — meanings for present and missing numbers
- **Clean, responsive UI** — works on desktop and mobile
- **Fully client-side** — no backend, no data leaves your browser

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Quick Start

No build step required:

```bash
npx serve .
# or
python3 -m http.server 8000
```

Open `http://localhost:8000` (`index.html` is the entry point).
